# Отчёт по практической работе 3
## 1. Числа как байты
| Значение | Прогноз  | Реальность  | HEX            |
| -------: | ------:  | ---------:  | ---            |
|        1 |    4     | 4           |01 00 00 00     |
|       -1 |     4    |  4          |FF FF FF FF     |
|     1000 |      4   |   4         |E8 03 00 00     |
|  1000000 |       4  |    4        |40 42 0F 00     |
### Вывод
всегда 4 байта.Менялось только содердимое
## 2. Переполнение
### Гипотеза
Что произойдёт с int.MaxValue + 1? А с int.MinValue - 1?
### Результат
MaxValue + 1 → −2147483648
MinValue − 1 → 2147483647
## 3. Текст как байты
| Текст  | Символов  | UTF-8 байтов |
